Upstream lsm.c:460-511 seeds a file-context label at allocation; __FMODE_EXEC
opens cache MAY_EXEC|MAY_READ|AA_EXEC_MMAP. This is a cache on the file, not a
source-policy m rule. common_mmap:555-587 separately requests AA_EXEC_MMAP for
PROT_EXEC and passes current credentials into aa_file_perm. It also mediates
file-backed mprotect. file.c:483-541 and619-670 distinguish current task label,
file cached label and cached allowed mask. Revalidation can examine profiles in
the current label and in the file label, depending on cache state; a denial's
profile name alone does not prove the final userspace task label or that Px
failed to select its target. Unconfined-opened file delegation is a special
short circuit in this reference implementation. bprm credentials and ELF file
mappings are different checks; begin_new_exec and ELF mapping failures beyond
the point of no return can terminate execution. This corroborates why a granted
exec does not establish successful userspace entry. We do NOT assert the exact
unobserved cached-label history or crash internals of live17 from upstream code.
