latex.ltx:98 begins \ifnum\catcode`\{=1. This intentionally checks the initex
category state before setting brace catcodes. Current expander has no ifnum,
integer scanner, mutable category-code table or initex bootstrap. The kernel
must not simply be prepended to an already formatted document environment.
Later \let\bgroup={ illustrates token-meaning assignment, not text aliasing.

amsmath.sty:24 first invokes \NeedsTeXFormat; format/version/release/package
kernel services must already exist. Even if those are supplied, line30

catcode reads, stable replacement tokens and later restoration. Implementing
only a name 'edef' cannot make this safe. Later \catcode/\string/\noexpand,
AtEndOfPackage, option conditionals and registers need stateful interpretation.

requires TeX input translation before tokenization. Fixed ASCII+@ name scanning
or stripping comments once at load time cannot reproduce this behavior.
