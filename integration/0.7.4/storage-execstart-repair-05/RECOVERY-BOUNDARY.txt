WHAT IS IMPLEMENTED
recovery_check.py is a READ-ONLY authenticator, with no ledger writer or launcher.
It validates pinned operational state and the independent original failure result,
STOP binding, root-review pin, exact old controller/helper/config bundle, original
manifest/grant/source pins and declared historical commit (not current repo HEAD).
It derives exact service/outer argv from those pins, checks historical policy/charge,
and compares the recorded invocation to two fresh systemd property/ExecStart reads.
It requires terminal exit1, exact resource properties, completed timestamps and PID,
same boot, both PIDs absent before/after, and the exact cgroup empty before/after.
The source/state pins are revalidated after those samples. Old argv with spaces
stays a JSON argument vector; neither substring matching nor shell splitting occurs.
An absent service cgroup under the still-known hierarchy counts as no members.
Permission/read errors, missing unit, malformed response and pin mismatch fail closed.
The observed proof is a sample; it is NOT a release capability or normal join receipt.
