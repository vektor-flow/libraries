Bibliography and citation VKF helpers, checkpoint 2026-10-16

Production APIs:
 bibliography.prepare(source, files_json="{}", entry="", options=[],
                      label_widths_json="{}")
   -> source, labels_json, entries_json, inputs_json, diagnostics_json,
      separator, style, complete.
 All JSON-suffixed fields are complete JSON values. Resource files are raw .bib
 strings or objects containing text. Uses generic database parsing, string
 definitions, concatenation, cross-reference inheritance, author names, supported
 entry formatting, numeric/alphabetic labels and sorted bibliography selection.
 Caller passes actual biblatex requestedOptions array without normalizing spaces.
 Unsupported styles/options/entry types/unknown collation weights stay explicit.

 bibliography.set_widest(prepared_source, widest_label, original_source="") -> source
 Pass the exact input source supplied to prepare as original_source to preserve
 manual environments while changing generated printbibliography environments.
 Omitting the third argument preserves the original API behavior (all widths).
 Caller measures label glyph advances using actual class fonts, matching JS
 prepareBiblatex measureLabel, without parsing the database twice.

 document_citations.collect(source, initial_labels_json="{}") -> labels_json
 Call after macro expansion to merge manual bibitem labels; default numbering
 uses current map size + 1, preserving the JS duplicate-key behavior.

 document_citations.resolve(source, labels_json="{}", separator=",~",
                            biblatex=false, links=false, legacy=false)
   -> source, diagnostics
 diagnostics is a quoted JSON member list WITHOUT surrounding brackets.
 Includes both optional citation notes, missing key diagnostics, explicit
 unimplemented textual author citation warning, literal protection and native
 documentlinkspan/legacy documentlink wrappers. URI destinations use document_uri.
 For biblatex use prepare.separator ("; "); manual bibliographies use ",~".
