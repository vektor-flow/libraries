# Typed document host API

Import `createDocumentRenderSession` from `document_render_session.mjs` and construct with `{device,pipeline}`. This is a callable host boundary; compiled A/C producer integration remains outstanding. It does not parse LaTeX, shape text, export PDF, or qualify real GPU/renderer latency. The frozen JavaScript reference renderer is unchanged.

`session.update(result)` requires `complete === true`, empty `diagnostics` and `unresolved`, `scene: {arena}`, source-owner `metadata`, a glyph `tiles` Map and decoded `resources`. Arena columns, kind dispatch and sixteen-number draw mapping are defined by `document_scene_bridge.mjs`; the exact checked numeric packet ABI is `prepareTypedPacket` in `document_typed_bridge.mjs` (16 aligned, finite Float64Array columns, same count, no SharedArrayBuffer). Source IDs must be explicit, unique and stable: metadata supplies documentId/revision, leafIds, nonoverlapping groups with contentVersion/layoutVersion/dependencies, resources with versions, leafResources, links and image/glyph bindings. Glyph tiles provide resourceId, plane and UV Float64 columns. Resources provide id/version, Uint8Array bytes and tightly packed rgba8unorm/straight image descriptors. Same resource version cannot change bytes or descriptor. The first successful bridge commit binds document ownership; foreign documents are rejected.

Update snapshots caller data synchronously and returns a promise for upload admission. Failed replacement retains the prior drawable. Await update before rendering. `await session.render(view,{zoom,origin,signal})` returns `{submission,generation,completion}`; await `completion` for queue completion, never PDF save. View supplies canvas dimensions, context texture acquisition and scale. Encoded draws retain immutable generation resources until submission completion or cancellation. `cancel()` revokes pending display intent; it does not pretend submitted work completed. `await dispose()` joins pending operations and releases ownership. Device loss terminates work. Low-level bridge snapshot leases must be released exactly once (release is idempotent); consumer replace takes lease ownership even on failure. CPU public byte access copies; no physical zero-copy claim. Exact equal instance bytes reuse immutable buffers only while generations retain them.

Run from repository root: `node --test examples/gpu-math/native-vkf/verify_document_host.mjs`. Seven isolated mock suites verify 69 stable IDs in `host/tests/registry.json`, with 30-second child deadlines. Optional VKF_HOST_OUTPUT_DIR retains JSON outputs. No worker directory or external asset is needed. Tests use eight existing MIT fixture bytes with source hash provenance. Inert historical originals and a failing allocation assertion are retained under tests/history; failure is not reclassified as acceptance. The named changed-geometry successor preserves the new-buffer failure path. Production module bytes are unchanged from the sealed host candidate.
