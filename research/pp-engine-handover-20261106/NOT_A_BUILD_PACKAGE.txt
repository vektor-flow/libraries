This handover is source/evidence for optional upstream reuse. It is not an
installed SDK or complete runnable compiler project. Canonical Git refs and
hashes are in INVENTORY.json. Historical test imports/build scripts refer to
their original checkouts; do not adopt those paths as a public engine contract.
Large ignored recordings/reference .bin caches remain local evidence, not a
public release. CPU reference tests live in physics-reference; requirements.txt
records their Python dependencies. The normal automatic GPU compiler/core/API
and genuine hardware qualification take precedence over these experiments.
